# IoT Smart Home Automation System 

# Overview
The IoT Home Automation System is designed to monitor and automate various home environment parameters using sensors, control modules, and IoT connectivity. 
The system integrates temperature monitoring, ambient light sensing, water tank level monitoring, LCD display output, and remote monitoring through the Blynk platform.
This project demonstrates the application of embedded systems and IoT technologies for smart home automation and real-time environmental monitoring.

-----------------------------

## Features
* Temperature monitoring and control
* Automatic heater and cooler operation
* Ambient light sensing using LDR
* Water tank level monitoring
* Real-time status display on LCD
* Remote monitoring through Blynk IoT platform
* Automated control logic for environmental management

## System Modules

### Temperature Monitoring System
Monitors the surrounding temperature and automatically controls heating and cooling devices based on predefined conditions.

### Light Monitoring System
Uses an LDR sensor to measure ambient light intensity and perform brightness-based automation.

### Water Tank Monitoring System
Tracks water level conditions and provides monitoring and control functionality for efficient water management.

### LCD Display Interface
Displays real-time information including temperature, water level status, and system control states.

### IoT Connectivity
Provides remote monitoring and interaction capabilities through the Blynk platform.
